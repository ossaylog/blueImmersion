# BLUE IMMERSION — 최종 에셋 목록

현재 MVP는 **모든 3D 모델·애니메이션·사운드를 코드로 절차 생성**합니다(외부 파일 0개).
아래는 최종 품질을 위해 교체가 필요한 에셋과, 교체 시 지켜야 할 규격입니다.
교체 원칙: **로직은 그대로, 렌더러만 교체** — 각 항목의 "연결 지점"에 같은 이름/슬롯으로 붙이면 됩니다.

공통 규격: glTF 2.0 (.glb), Draco 또는 Meshopt 압축, KTX2(Basis) 텍스처, 1 unit = 1 m, +Z 전방, +Y 위.
모바일 기준 예산은 괄호 안에 표기.

## 2. 해양 생물

현재: 종별 체형 파라미터 + 무늬 셰이더(절차). 아래 모델로 교체하면 `FishSystem`의 행동·꼬리 파동(정점 셰이더)이 그대로 적용됩니다 —
**정점 속성 `aBody`(0 꼬리 끝 → 1 주둥이)만 bake** 하면 스켈레톤 없이도 유영 애니메이션이 동작합니다(인스턴싱 유지).

## 5. 사운드 (현재: Web Audio 절차 합성)

| 채널 | 필요한 녹음 | 형식 |
|---|---|---|
| 환경음 | 갑판 위 바람, 잔잔한 파도, 선체에 부딪히는 물, 수중 앰비언스(얕은 리프/깊은 블루), **딱총새우 크래클** 루프 | 48kHz OGG/AAC, 60~120초 무봉제 루프 |

| 생물 | 물고기 무리 스침, 거북 지느러미, 앵무고기 산호 긁는 소리 | 원샷 |
| 연출 | 엔진(아이들/순항), 입수 첨벙(계단/자이언트 스트라이드), 수면 통과 | 원샷/루프 |
| 배경음악 | 선택형 앰비언트 2~3곡 (기본 꺼짐) | 루프 |

## 6. 텍스처·기타
- 커스틱: 현재 절차 셰이더 → 품질 '높음'에서는 16프레임 커스틱 플립북(1024)으로 선명도 향상 가능
- 수면 노멀맵 2장(512, 스크롤) — 원경 잔물결 보강
- UI 아이콘 세트(SVG), 생물 도감 일러스트(향후)
