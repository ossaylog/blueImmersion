# BLUE IMMERSION — MVP (Phase 1~6 기본)

웹 브라우저에서 바로 들어가는 스노클링 & 스쿠버다이빙 가상 해양 탐험.

## 실행
```bash
npm install
npm run dev        # http://localhost:5173  (같은 Wi-Fi 휴대폰에서는 Network 주소로 접속)
npm run build      # dist/index.html 단일 파일 (서버 없이 열기 가능)
```

### 멀티유저 (함께 다이빙)
- `npm run dev` / `npm run preview` 서버에 멀티유저 릴레이(웹소켓 `/mp`)가 자동으로 붙어요. 같은 주소로 접속한 사람끼리 같은 바다에서 서로 보여요.
- 배포·상시 운영: `npm run server` → 빌드 후 `http://<서버주소>:8787` (포트는 `PORT` 환경변수)
- 접속할 때마다 한글로만 된 랜덤 닉네임(예: `느긋한 해마`, 겹치면 `달빛 느긋한 해마`)이 정해지고, 각 캐릭터 머리 위에 닉네임이 표시돼요. 우상단에 접속 인원이 보여요.
- 서버 없이 `dist/index.html`을 직접 열면, 같은 브라우저의 다른 탭끼리만 연결돼요.
- 다른 릴레이 서버 지정: `?mp=wss://example.com/mp`
- **같은 바다, 같은 생물**: 접속하면 서버 시계와 맞추고(`/mp`의 `time` 메시지), 생물은 그 공유 시계 + 시드 난수로 계산돼요. 같은 바다에 있는 모든 사람이 같은 시각·같은 위치에서 같은 생물(무리·경로·먹는 산호까지)을 봐요. 생물을 보내는 호스트가 없어서 누가 나가거나 탭을 내려도 바다가 멈추지 않아요 (`src/life/Ecology.ts`)
- 도메인 연결 시 HTTPS라면 웹소켓도 `wss://<도메인>/mp`로 붙으니, 리버스 프록시(Caddy·nginx)에서 웹소켓 업그레이드를 허용해 주세요

### 개발·검수용 URL 파라미터
| 파라미터 | 동작 |
|---|---|
| `?go=snorkel` | 바로 스노클링 수중으로 |
| `?go=scuba` | 바로 스쿠버 4m 지점으로 |
| `?go=deck` | 판툰 1층에서 바로 자유 이동 |
| `?go=dock` | 배가 판툰에 도착하는 장면부터 |
| `?q=low` / `?q=high` | 그래픽 품질 강제 (기본: 모바일 low, PC high) |

## 조작
| | PC | 모바일 |
|---|---|---|
| 이동 | W A S D (판툰 위에서는 걷기) | 왼쪽 아래 조이스틱 (강도 비례) |
| 판툰 | F 선베드에 눕기·일어나기 · 존에 들어서면 시점 선택 | 🛏 버튼 · 시점 카드 |
| 지도 | M 또는 🗺 지도 · 오른쪽 위 미니맵 클릭 | 🗺 지도 · 미니맵 터치 |
| 시점 | 마우스 드래그, 휠=거리 | 화면 드래그 (조이스틱과 멀티터치 분리) |
| 스노클링 | Shift 잠수(놓으면 그 깊이 유지, 최대 5m) · Space 수면으로 / 수면에서 고개 들기 · S 손 스컬링으로 후진 | 잠수·수면 버튼 |
| 스쿠버 | Space 상승(약 21 m/min, 수면에서 계속 누르면 물 밖으로) · Shift 하강 · Q 정지 · S 백킥 후진 | 상승·정지·하강 버튼 |
| 시점 전환 | V 또는 우상단 버튼 (버튼에는 바뀔 시점이 표시됨) | 우상단 버튼 |
| 기타 | Esc 지도·설정·컬렉션 닫기 · 📖 바다 생물 컬렉션 | 우상단 📖·설정·판툰으로 복귀 |

### 리프 판툰 (도착 · 대기 · 입수)
- 셔틀 보트가 리프 한가운데 계류된 2층 판툰(호주 그레이트배리어리프 방식) 좌현에 붙으면, 판툰의 현문 사다리가 배 게이트에 걸쳐지고 그 위를 걸어 넘어가요
- 판툰에 넘어오면 자유롭게 걸어 다녀요: 1층 카페·식당·파라솔, 선수 계단(14단)으로 2층 전망 데크에 올라가 선베드에 눕거나 경치 감상
- 우현 **스노클 존** / 선미 **다이빙 데크**에 들어서면 1인칭·3인칭을 고르는 카드가 떠요 → 고르면 장비 랙·벤치에서 착용하고 바로 입수 (카드는 "조금 더 둘러볼게요"로 닫을 수 있음)
- 스노클: 우현 계단 → 플랫폼 → 물에 잠긴 계단에 앉아 오리발을 신고 밀고 나감 · 스쿠버: 선미 다이빙 플랫폼 끝에서 난간을 잡고 오리발 → 자이언트 스트라이드
- 걸을 때 발은 한 걸음씩 실제 디딤판 높이에 딛도록(IK) 계산돼요
- 멀티유저 위치는 판툰 기준 좌표로 공유되어, 다른 사람이 돌아다니거나 선베드에 누워 있거나 장비를 입거나 계단을 내려가는 모습이 같은 자리에 보여요
- 판툰: `src/world/Pontoon.ts` · 자유 이동·층·충돌: `src/world/Deck.ts` · 발자국 걷기: `src/world/Walker.ts` · 지도: `src/ui/MapView.ts`

### 산호를 먹는 물고기
- 앵무고기·혹돔앵무고기: 머리를 크게 숙여 산호 표면을 긁고, 물 때마다 고개를 흔들며 하얀 산호 가루가 날려요
- 나비고기·무어리시 아이돌·리갈 엔젤피시·황제/퀸 엔젤피시: 산호 폴립·해면을 콕콕 쪼고 가끔 멈춰 둘러봐요 (나비고기는 짝이 옆 산호를 함께 쪼아요)
- 블루탱·옐로탱·가리발디: 산호와 바위의 해조류를 연달아 뜯어요 · 나폴레옹피시: 두툼한 입술로 산호 잔해 틈을 들춰요
- 흰동가리: 말미잘 촉수 위를 까딱이며 맴돌고 자주 촉수 사이로 파고들어 몸을 비벼요. 누가 다가오면 촉수 깊이 숨어 침입자를 마주보고, 가장 큰 암컷은 조금 앞에서 지켜요

### 수영 동작
- 스노클링: 수면에서 플러터 킥(엉덩이부터 곧게 차는 발차기), 후진은 손 스컬링, 잠수는 덕다이브
- 스쿠버: 개구리차기(접기 → 밀기 → 활주), 후진은 백킥, 제자리 방향 전환은 헬리콥터 턴, 멈추면 프로그 포지션 호버링
- 수면 위: 머리만 내밀고 선헤엄 · 수평선의 섬, 구름, 바닷새, 배 위치(⛵ 표시)가 보이고, 물 밖으로 나온 순간 마스크에 물방울이 맺혀요
